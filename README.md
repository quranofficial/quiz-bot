# 📚 بۆتی کویزی تێلێگرام (Telegram Quiz Bot)

بۆتێکی کویزی کوردی بە زمانی Python کە بە تەواوی لەسەر **GitHub Actions** کار دەکات — بەبێ سێرڤەر و بەخۆڕایی. داتاکان لە فایلی `data/db.json` لەناو هەمان ڕیپۆدا هەڵدەگیرێن و بۆت خۆی دوای هەر گۆڕانکارییەک بۆ GitHub پوشی دەکات، بۆیە هیچ داتایەک لەدەست ناچێت.

---

## ✨ تایبەتمەندییەکان

**لای بەکارهێنەر:**
- 🗂 ڕاوکردنی بەشەکان بە شێوەی دارچین: بەش → کەرت → کەرتی ناوخۆیی... (بێ سنوور)
- 📝 کویزی هەڕەمەکی — هەموو پرسیارەکانی بەشەکە بە ڕیزبەندی هەڕەمەکی دێن
- ✅ دوای هەر وەڵامێک، دەستبەجێ ڕاست/هەڵە بوونەکە نیشان دەدرێت لەگەڵ وەڵامی ڕاست
- 📊 لە کۆتاییدا ئەنجامی ورد: ژمارەی ڕاست و هەڵە، ڕێژە، و لیستی هەموو پرسیارەکان لەگەڵ وەڵامی ڕاستی هەڵەکان
- 🖼 پرسیاری وێنەدار و بێ وێنە
- 📄 پەڕەکانی تێبینی (کەش): نووسین، وێنە یان فایل

**لای ئادمین:**
- ➕ زیادکردنی بەش و کەرت بە قووڵایی بێ سنوور
- ➕ ویزاردی زیادکردنی پرسیار: وێنە (ئارەزوومەندانە) → دەق → هەڵبژاردەکان (٢ بۆ ٦) → دیاریکردنی وەڵامی ڕاست
- ✏️ دەستکاری دەق و وێنەی پرسیار، 🗑 سڕینەوەی بەش/پرسیار
- 👥 زیادکردن/لابردنی ئادمین بە ID
- ⚙️ ڕێکخستنی ژمارەی پرسیارەکانی هەر کویزێک (یان «هەمووی»)
- 📊 ئامار

## 🚀 دامەزراندن — هەنگاو بە هەنگاو

### ١. دروستکردنی بۆت لە BotFather
1. لە تێلێگرام بڕۆ بۆ [@BotFather](https://t.me/BotFather)
2. بنووسە `/newbot` و ناو و usernameـی بۆتەکە دابنێ
3. **توکینەکە** کۆپی بکە (نموونە: `123456789:AAHfj...`)

### ٢. وەرگرتنی ID ی خۆت
بڕۆ بۆ [@userinfobot](https://t.me/userinfobot) — ژمارەی ID یت بۆ دەنێرێت (نموونە: `123456789`)

### ٣. دروستکردنی ڕیپۆ و بارکردنی کۆدەکە
1. لە GitHub ڕیپۆیەکی نوێ دروست بکە
   - 💡 **باشترە ڕیپۆکە Public بێت** — لە ڕیپۆی Public دا GitHub Actions بێ سنوور و بەخۆڕاییە. لە ڕیپۆی Private دا مانگانە تەنها ٢٠٠٠ خولەکی خۆڕایی هەیە کە بەسەر نایەت!
2. هەموو فایلەکانی ئەم پڕۆژەیە بارکە (Upload) یان بە git پوشی بکە:
   ```bash
   git init
   git add .
   git commit -m "quiz bot"
   git branch -M main
   git remote add origin https://github.com/USER/REPO.git
   git push -u origin main
   ```

### ٤. دانانی Secrets
لە ڕیپۆکەت: **Settings → Secrets and variables → Actions → New repository secret**

| Name | Value |
|------|-------|
| `BOT_TOKEN` | توکینی بۆتەکە لە BotFather |
| `OWNER_ID` | ID ی تۆ (ژمارە) |

### ٥. چالاککردنی بۆتەکە
1. لە ڕیپۆکەت بڕۆ بۆ تابی **Actions**
2. «Telegram Quiz Bot» هەڵبژێرە → **Run workflow** → بنووسە **Run workflow**
3. تەمام! لەمەودوا هەر ٥ خولەک خۆکارانە دووبارە دەست پێدەکاتەوە و بۆت ٢٤ کاتژمێر ئۆنلاین دەمێنێتەوە.

> ⚠️ **تێبینی**: GitHub هەر ڕێکخراوێکی کاتی (schedule) دوای ٦٠ ڕۆژ بێ چالاکی لە ڕیپۆدا ناچالاک دەکات. تەنها یەک commit ی نوێ بکە (یان لە بۆتەکە پرسیار زیاد بکە — بۆت خۆی commit دەکات!) و دووبارە چالاک دەبێتەوە.

## 🛠 چۆنیەتی بەکارهێنان

### بۆ بەکارهێنەر
1. `/start` بنێرە → «📚 بەشەکان» بکەرەوە
2. بەشێک هەڵبژێرە (دەتوانیت بچیتە ناو کەرتەکانیش)
3. «📝 دەستپێکردنی کویز» بکە — پرسیارەکان بە هەڕەمەکی دێن
4. دوای هەر وەڵامێک ✅/❌ دەبینیت
5. لە کۆتاییدا ئەنجامە وردەکە دێت + دوگمەی «🔁 دووبارەکردنەوە»

### بۆ ئادمین
`/admin` بنێرە (یان دوگمەی 🛠 پانێڵی ئادمین):

- **📂 بەش و پرسیارەکان** — کلیک لە «➕ بەشی نوێ» بکە بۆ بەشێکی نوێ. پاشان کلیک لە بەشەکە بکە و «➕ پرسیاری نوێ»:
  1. وێنەی پرسیارەکە بنێرە (یان «⏭ بەبێ وێنە») — ئەگەر کاپشنی لەگەڵ بنێریت وەک دەقی پرسیار دادەنرێت
  2. دەقی پرسیارەکە بنێرە
  3. هەر هەڵبژاردەیەک لە پەیامێکی جیا بنێرە (٢ بۆ ٦)، پاشان «✅ تەواو» بکە
  4. دوگمەی وەڵامی ڕاست بکە — پرسیارەکە تۆمار دەکرێت!
- **📄 پەڕەکانی زانیاری (کەش)** — پەڕەی نوێ دروست بکە (نموونە: تێبینیەکان)، پاشان هەر کاتێک ویستت نووسین/وێنە/فایلی تێدا بڵاو بکەرەوە
- **👥 ئادمینەکان** — زیادکردنی ئادمینی نوێ بە ID (خاوەن لە Secrets دایە و ناسڕدرێتەوە)
- **⚙️ ڕێکخستنەکان** — ژمارەی پرسیارەکانی هەر کویزێک (نموونە: ١٠ یان «♾ هەمووی»)
- **📊 ئامار** — کۆی بەش و پرسیار و پەڕەکان

## ⏱ ڕێکخستنی کارکردنی ٢٤ کاتژمێر

بۆت لە دوو مۆددا کار دەکات (بە گۆڕینی `POLL_SECONDS` لە فایلی workflow):

| مۆد | POLL_SECONDS | چۆنیەتی |
|-----|-------------|---------|
| **هەر ٥ خولەک** (بنەڕەت) | `240` | هەر دانیشتێک ٤ خولەک پۆڵینگ دەکات؛ دواکەوتنی وەڵام هەتا ~٢ خولەک لە کاتی نوێبوونەوەدا |
| **کارکردنی درێژ** | `19200` (٥.٣ کاتژمێر) | بۆت نزیکەی بێ پشوو کار دەکات؛ تەنها هەر ٥.٥ کاتژمێر جارێک نوێ دەبێتەوە (~١ خولەک پشوو) |

> 💡 مۆدی درێژ زۆر باشترە، بەڵام لە ڕیپۆی **Private** دا خاڵی Actions زۆر بەکاردەهێنێت. لە ڕیپۆی **Public** دا بێ سنوورە — ئەگەر ڕیپۆکە Publicـە، `POLL_SECONDS: "19200"` دابنێ.

## 💻 کارپێکردن لەسەر کۆمپیوتەر (بۆ تاقیکردنەوە)

```bash
pip install -r requirements.txt
set BOT_TOKEN=توکینەکە        # لە لینوکسدا: export BOT_TOKEN=...
set OWNER_ID=ID ی خۆت
python bot.py
```

لەسەر کۆمپیوتەر داتا تەنها لە فایل هەڵدەگیرێت (بێ پوش بۆ GitHub — ئەگەر ڕیپۆی git هەبێت، خۆکارانە پوش دەکات).

## ❓ پرسیارە باوەکان

**داتاکان لە کوێن؟** لە `data/db.json` — هەموو گۆڕانکارییەک بە خۆکاری commit دەکرێت، بۆیە مێژووی git وەک باکئەپێک کاردەکات.

**چۆن شتێک بسڕمەوە؟** لە پانێڵی ئادمین، بەش/پرسیار/پەڕە بکەرەوە و دوگمەی 🗑 بکە (دوو هەنگاوی دڵنیابوون هەیە).

**وێنەی پرسیار چۆن هەڵدەگیرێت؟** تەنها `file_id` ی تێلێگرام — بۆیە هیچ فایلێک لە ڕیپۆدا نییە و ڕیپۆکە قورس نابێت.

**پرسیارەکان دەتوانن لە چەند بەشێک بن؟** هەر پرسیارێک لە یەک شوێندایە، بەڵام بەشەکان بێ سنوور قووڵ دەبنەوە — کویزی هەر بەشی باوک هەموو پرسیارەکانی کەرتەکانی لەخۆ دەگرێت.

**وەڵام ناداتەوە؟** تابی Actions لە ڕیپۆکە ببینە — ئەگەر هەڵەیەک هەبێت لە لۆگەکەدا دەردەکەوێت. زۆربەی کاتان ئەوەیە کە Secretsـەکان سن نەنراون.

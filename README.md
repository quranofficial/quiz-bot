# 📚 بۆتی تاقیکردنەوەی تێلێگرام (Telegram Quiz Bot)

بۆتێکی تاقیکردنەوەی کوردی بە زمانی Python کە بە تەواوی لەسەر **GitHub Actions** کار دەکات — بەبێ سێرڤەر و بەخۆڕایی، و **٢٤ کاتژمێر لە ڕۆژێکدا / ٧ ڕۆژ لە هەفتەیەکدا** ئۆنلاین دەمێنێتەوە. داتاکان لە فایلی `data/db.json` لەناو هەمان ڕیپۆدا هەڵدەگیرێن و بۆت خۆی دوای هەر گۆڕانکارییەک بۆ GitHub پوشی دەکات، بۆیە هیچ داتایەک لەدەست ناچێت.

---

## ✨ تایبەتمەندییەکان

**لای بەکارهێنەر:**
- 👤 **تۆمارکردنی یەکەم جار**: لە `/start` دا ناوی و ئەوەی قوتابی مامۆستایە یان نا دەپڕسرێت و خەزن دەکرێت
- 🗂 ڕاوکردنی بەشەکان بە شێوەی دارچین: بەش → کەرت → کەرتی ناوخۆیی... (بێ سنوور)
- 🔢 **٣ بژاردە پێش دەستپێکردنی تاقیکردنەوە**: ١٠ پرسیار / سەرجەم پرسیارەکان (ژمارەکە پیشان دەدرێت) / دیاریکردن بە ژمارە
- 🎯 **تاقیکردنەوەی تایبەت**: بەکارهێنەر ٢ یان ٣ بەش (یان ناو یەک بەش ٣ کەرت) خۆی هەڵدەبژێرێت و تاقیکردنەوەی تێکەڵ دروست دەکات
- ✅ دوای هەر وەڵامێک، دەستبەجێ ڕاست/هەڵە بوونەکە نیشان دەدرێت لەگەڵ وەڵامی ڕاست
- 🎨 **فۆرماتکردنی دەق**: قەڵەو، لادان، شاراوە (Spoiler)، کۆد و وشەی سوور 🔴 (بڕوانە بەشی فۆرمات)
- 📊 لە کۆتاییدا ئەنجامی ورد: ژمارەی ڕاست و هەڵە، ڕێژە، و لیستی هەموو پرسیارەکان
- ⚠️ **ڕاپۆرتکردنی کێشە**: لە کۆتایی تاقیکردنەوە، قوتابی دەتوانێت گومانی لە پرسیارێک بکات و بنێری — ئادمین بە replay وەڵامی دەداتەوە
- ⏰ **تاقیکردنەوەی شەوانە**: تاقیکردنەوەی کاتدار (نموونە ٩:٠٠–٩:٣٠ شەو) — هەر ئەکاونتێک ١ جار، لە کۆتاییدا ڕیزبەندی ئەنجامەکان بۆ هەموو بەژداران دەنێردرێت 🏆
- 🗃 **فڵاشکارت**: بەکارهێنەر بۆ خۆی کارت دروست دەکات (لای ١: پرسیار، لای ٢: وەڵام) و لێی دەدات
- 📊 **ئامارەکەم**: کۆی تاقیکردنەوەکان، ڕێژەی سەرکەوتن
- 🏠 دوگمەی «مینیوی سەرەکی» لە هەموو شوێنێکدا — لە ناوەڕاستی تاقیکردنەوەیشدا دەوەستێت
- 🙋 **پرسیار بکە**: بەکارهێنەر بەش و کەرت هەڵدەبژێرێت، پرسیاری دەنووسێت (+ وێنە) و ڕاستەوخۆ دەچێتە ئادمین — ئادمین وەڵام دەداتەوە و دەگاتە بەکارهێنەر
- 🖼 پرسیاری وێنەدار و بێ وێنە
- 📄 پەڕەکانی تێبینی (کەش): نووسین، وێنە یان فایل
- 📩 **پرسیارەکانم** و ⚠️ **ڕاپۆرتەکانم**: بەکارهێنەر هەموو کاتێک سەیری هەموو پرسیار و ڕاپۆرتەکانی دەکات و دۆخ و وەڵامەکانیان دەبینێت
- 📥 **نامە هاتووەکان**: نامە تایبەتەکانی ئادمین پاشەکەوت دەبن و هەر کاتێک ویست ویستیان دەبینێتەوە
- 🔒 **پاراستنی ناوەڕۆک**: هیچ پەیامێکی بۆت ناتوانرێت Forward یان Save بکرێت

**لای ئادمین:**
- 👤 **ژمارەی بەکارهێنەران** ڕاستەوخۆ لە سەرەتای پانێڵدا دیارە
- 🎓 **ژمارەی قوتابیەکان و ناقوتابییەکان** لە بەشی بەکارهێنەراندا (لە وەڵامی پرسیاری تۆمارکردنەوە)
- 📩 **نامەی تایبەت** بۆ هەر بەکارهێنەرێک لەناو پرۆفایلیەوە
- ➕ زیادکردنی بەش و کەرت بە قووڵایی بێ سنوور
- ➕ ویزاردی زیادکردنی پرسیار: وێنە (ئارەزوومەندانە) → دەق → **وشەی سوور** → هەڵبژاردەکان (تەنها ٤: A، B، C، D) → دیاریکردنی وەڵامی ڕاست
- 📥 **هێنانی پرسیار بە PDF یان وێنە** — دەیان پرسیار لە یەک کاتدا: سەرەتا بەش و کەرت هەڵدەبژێریت، پاشان فایلەکە دەنێریت؛ ئەگەر وەڵامی ڕاست لەسەر فایلەکە بنووسرابێت (وەڵام: B / Answer: C / ✅) خۆکاری زیاد دەکرێت، ئەگینا بە دەست بە دوگمە دیاری دەکرێت (OCR بۆ وێنە و PDF ی وێنەدار)
- 📩 **پرسیارەکانی بەکارهێنەران**: بە زانیاری بەکارهێنەر — ✉️ وەڵامدانەوە و 🔒 داخستن
- ⚠️ **ڕاپۆرتەکان**: ڕاپۆرتی کێشەی پرسیارەکان لەگەڵ زانیاری قوتابی — ✉️ وەڵام (دەگاتە قوتابی)، 🔒 داخستن، 🗑 سڕینەوە و 🧹 پاککردنەوەی داخراوەکان
- 👥 **بەکارهێنەران**: لیستی هەموو بەژداران (پەڕەبەند) + 🔍 گەڕان بە ناو/یوزەرنام/ID + 📊 ئاماری تەواوی هەر قوتابییەک (تاقیکردنەوەکان، ڕێژە، بەپێی بەش، ئەنجامی شەوانە)
- ⏰ **تاقیکردنەوەی شەوانە**: دروستکردن (ناو → کات)، پاشان سەرچاوەی پرسیارەکان بە دوو ڕێگا:
  • 📚 **لە بەشێک یان کەرتێک وەربگرە** + ژمارە (١٠ / ٢٠ / ژمارەیەک بنووسە / ♾ هەمووی)
  • ✍️ **پرسیاری نوێ بنووسە** — بەنکۆی تایبەت بۆ تاقیکردنەوەی شەوانە (بە وێنە یان بێ وێنە)
  • 👁 پیشاندان/شاردنەوە لە مینیو، 🏆 بینینی ئەنجامەکان
- 📢 **نامەی گشتی (Notification)**: نامە بۆ هەموو بەکارهێنەرانی تۆمارکراو (نموونە: «٥ خولەک ماوە بۆ دەستپێکردن»)
- ✏️ دەستکاری تەواوی پرسیار: دەق، وێنە، هەموو هەڵبژاردەکانی A-D و وەڵامی ڕاست، 🗑 سڕینەوەی بەش/پرسیار
- 🎛 **بەڕێوەبردنی مینیوی سەرەکی**: گۆڕینی ناوی هەموو دوگمەکانی مینیو بە تەواوی + زیادکردنی بەشی نوێ بۆ مینیو
- ⚠️ **پرسیاری بێ وەڵام**: ژمارەی پرسیارە بێ وەڵامەکان لە پانێڵدا دیارە و بە دوگمە بە دەست وەڵامیان دیاری دەکرێت
- 👥 زیادکردن/لابردنی ئادمین بە ID
- ⚙️ ڕێکخستنی ژمارەی پرسیارەکانی هەر تاقیکردنەوەیەک (یان «هەمووی»)
- 💬 **دوگمەکانی فەرمان**: لای بەکارهێنەر تەنها `/start` و `/help` دیارن؛ لای ئادمین `/admin`ـیش زیادە
- 📊 ئامار: بەش، پرسیار، پەڕە، بەکارهێنەری تۆمارکراو، پرسیاری کراوە، ڕاپۆرت، تاقیکردنەوەی چالاک
- ⚡ **خێرایی**: چەندین بەکارهێنەر لە هەمان کاتدا وەڵام وەردەگرن (concurrent updates)
- 🚀 **هیچ بێدەنگییەک نییە**: بۆ هەر پەیامێک لە کاتی زیادکردنی شتەکاندا، بۆت هەمیشە وەڵام دەداتەوە — تەنانەت ئەگەر جۆری پەیامەکە لەگەڵ هەنگاوەکە ناگونجێت

## 🚀 دامەزراندن — هەنگاو بە هەنگاو

### ١. دروستکردنی بۆت لە BotFather
1. لە تێلێگرام بڕۆ بۆ [@BotFather](https://t.me/BotFather)
2. بنووسە `/newbot` و ناو و usernameـی بۆتەکە دابنێ
3. **توکینەکە** کۆپی بکە (نموونە: `123456789:AAHfj...`)

### ٢. وەرگرتنی ID ی خۆت
بڕۆ بۆ [@userinfobot](https://t.me/userinfobot) — ژمارەی ID یت بۆ دەنێرێت (نموونە: `123456789`)

### ٣. دروستکردنی ڕیپۆ و بارکردنی کۆدەکە
1. لە GitHub ڕیپۆیەکی نوێ دروست بکە
   - 💡 **باشترە ڕیپۆکە Public بێت** — لە ڕیپۆی Public دا GitHub Actions بێ سنوور و بەخۆڕاییە. لە ڕیپۆی Private دا مانگانە تەنها ٢٠٠٠ خولەکی خۆڕایی هەیە کە بەسەر نایەت!
2. هەموو فایلەکانی ئەم پڕۆژەیە بارکە (Upload) یان بە git پوشی بکە:
   ```bash
   git init
   git add .
   git commit -m "quiz bot"
   git branch -M main
   git remote add origin https://github.com/USER/REPO.git
   git push -u origin main
   ```

### ٤. دانانی Secrets
لە ڕیپۆکەت: **Settings → Secrets and variables → Actions → New repository secret**

| Name | Value |
|------|-------|
| `BOT_TOKEN` | توکینی بۆتەکە لە BotFather |
| `OWNER_ID` | ID ی تۆ (ژمارە) |

### ٥. چالاککردنی بۆتەکە
1. لە ڕیپۆکەت بڕۆ بۆ تابی **Actions**
2. «Telegram Quiz Bot» هەڵبژێرە → **Run workflow** → بنووسە **Run workflow**
3. تەمام! لەمەودوا هەر ٥ خولەک خۆکارانە دووبارە دەست پێدەکاتەوە و بۆت ٢٤ کاتژمێر ئۆنلاین دەمێنێتەوە.

> ⚠️ **تێبینی**: GitHub هەر ڕێکخراوێکی کاتی (schedule) دوای ٦٠ ڕۆژ بێ چالاکی لە ڕیپۆدا ناچالاک دەکات. تەنها یەک commit ی نوێ بکە (یان لە بۆتەکە پرسیار زیاد بکە — بۆت خۆی commit دەکات!) و دووبارە چالاک دەبێتەوە.

## 🛠 چۆنیەتی بەکارهێنان

### بۆ بەکارهێنەر
1. `/start` بنێرە → جاری یەکەم: ناوی دەنووسرێت و پرسیاری «قوتابی مامۆستا (…) ی؟» وەڵام دەدرێتەوە — خەزن دەکرێت و دووبارە نایەتەوە
   > 💡 لای بەکارهێنەر تەنها دوگمەی `/start` و `/help` دیارن؛ لای ئادمین `/admin`ـیش زیادە — بۆ وەستاندنی هەر ویزاردێک `/cancel` بنێرە
2. «📚 بەشەکان» بکەرەوە، بەشێک هەڵبژێرە → ٣ بژاردە پێش دەستپێکردن: **١٠ پرسیار** / **سەرجەم** / **دیاریکردن بە ژمارە**
3. «🎯 تاقیکردنەوەی تایبەت» → ☑ دوو یان سێ بەش (یان ٣ کەرت) هەڵبژێرە → دەستپێکردن
4. «⏰ تاقیکردنەوەی شەوانە» → ئەگەر کاتی نەهاتووە، ماوەی ماوە پیشان دەدرێت؛ ئەگەر کراوەیە، بەژداری بکە (١ جار بۆ هەر ئەکاونتێک)
5. «🗂 فڵاشکارت» → کارتی نوێ: لای یەکەم → لای دووەم (+ وێنە ئارەزوومەندانە) → پاشان «▶️ لێدان»
6. لە کۆتایی هەر تاقیکردنەوەیەک: «⚠️ ڕاپۆرتکردنی کێشە» → پرسیاری گومانلێکراو هەڵبژێرە → لێدوانەکەت بنووسە
7. «🙋 پرسیار بکە» → بەش و کەرت هەڵبژێرە → پرسیارەکەت بنووسە (+ وێنە ئەگەر ویستت) → بنێرە
8. وەڵامی ئادمین وەک پەیام بۆت دێت: «📬 وەڵامی پرسیاری #…»

### بۆ ئادمین
`/admin` بنێرە (یان دوگمەی 🛠 پانێڵی ئادمین):

- **📂 بەش و پرسیارەکان** — کلیک لە «➕ بەشی نوێ» بکە بۆ بەشێکی نوێ. پاشان کلیک لە بەشەکە بکە و «➕ پرسیاری نوێ»:
  1. وێنەی پرسیارەکە بنێرە (یان «⏭ بەبێ وێنە») — ئەگەر کاپشنی لەگەڵ بنێریت وەک دەقی پرسیار دادەنرێت
  2. دەقی پرسیارەکە بنێرە — دەتوانیت فۆرمات بەکاربهێنیت (بڕوانە بەشی فۆرمات)
  3. **وشەی سوور**: ئەگەر دەتەوێت وشەیەک 🔴 بێت، هەمان وشە بنێرە (یان «⏭ بەبێ نیشانکردن»)
  4. هەر هەڵبژاردەیەک لە پەیامێکی جیا بنێرە (٢ بۆ ٦)، پاشان «✅ تەواو» بکە
  5. دوگمەی وەڵامی ڕاست بکە — پرسیارەکە تۆمار دەکرێت!
- **📥 هێنانی پرسیار بە JSON** — فایلی `.json` بنێرە یان دەقی JSON ڕاستەوخۆ بنێرە (بڕوانە بەشی JSON)
- **📩 پرسیارەکان** — پرسیارە بەکارهێنەران بە زانیاری تەواو: ✉️ وەڵامدانەوە (نووسین یان وێنە+کاپشن) یان 🔒 داخستن. ژمارەی کراوەکان لەسەر دوگمەکە دەردەکەوێت
- **⚠️ ڕاپۆرتەکان** — ڕاپۆرتی کێشەی قوتابیان: ✉️ وەڵام (ڕاستەوخۆ دەگاتە قوتابی)، 🔒 داخستن، 🗑 سڕینەوە. بە «🧹 سڕینەوەی داخراوەکان» ڕاپۆرتە کۆنەکان پاک دەکرێنەوە بۆ ئەوەی کەڵەکە نەبن
- **👥 بەکارهێنەران** — لیستی هەموو بەژداران + ژمارەی قوتابیەکان 🎓 و ناقوتابییەکان 🚫 لە سەرەوە؛ کلیک لەسەر ناوی هەر یەکێک → ئاماری تەواو (تاقیکردنەوەکان، ڕێژەی سەرکەوتن، بەپێی بەش، ئەنجامی شەوانە) + دوگمەی **📩 نامەی تایبەت** بۆ ناردنی نامە بۆ ئەو بەکارهێنەرە. بە 🔍 دەتوانیت بە ناو، یوزەرنام یان ID بگەڕێیت
- **⏰ تاقیکردنەوەی شەوانە**:
  1. «➕ دروستکردن» → ناوی تاقیکردنەوە → کاتی دەستپێک (نموونە: 21:00) → کاتی کۆتایی (21:30)
  2. «📝 گۆڕینی پرسیارەکان» → دوو ڕێگا:
     • **📚 لە بەشێک یان کەرتێک وەربگرە** → بەشەکە هەڵبژێرە → ژمارەی پرسیارەکان: «♾ هەمووی» / «١٠ پرسیار» / «٢٠ پرسیار» / یان ژمارەیەک بنووسە
     • **✍️ پرسیاری نوێ بنووسە** → بەنکۆی تایبەت بۆ تاقیکردنەوەی شەوانە: «➕ پرسیاری نوێ» بکە → وێنە بنێرە (یان «⏭ بەبێ وێنە») → دەق → هەڵبژاردەکان → وەڵامی ڕاست — هەر بەم شێوەیە هەر ١٠ پرسیار زیاد بکە؛ بە «🗑 سڕینەوەی دوایین پرسیار» دەتوانیت هەڵبژاردنی چاک بکەیت
  3. «👁 پیشاندان لە مینیو» — دوگمەکە بۆ بەکارهێنەران دەردەکەوێت؛ «🙈 شاردنەوە» — نامێنێت
  4. لە کۆتایی کاتدا، ڕیزبەندی ئەنجامەکان 🏆 بە خۆکاری بۆ هەموو بەژداران و ئادمینەکان دەنێردرێت (🥇🥈🥉)
  5. هەر ئەکاونتێک تەنها ١ جار لە ئەمشەودا دەتوانێت بەژداری بکات — ئەگەر پێش کات بکاتەوە، ماوەی ماوەی بۆ دەنووسرێت
- **📢 نامە بۆ هەمووان** — نووسین یان وێنە+کاپشن بنێرە و پشتڕاستی بکەرەوە؛ بۆ هەموو بەکارهێنەرانی تۆمارکراو دەچێت (نموونە: «٥ خولەک ماوە بۆ دەستپێکردنی تاقیکردنەوەی شەوانە»)
- **📄 پەڕەکانی زانیاری (کەش)** — پەڕەی نوێ دروست بکە، پاشان نووسین/وێنە/فایل بڵاو بکەرەوە
- **👥 ئادمینەکان** — زیادکردنی ئادمینی نوێ بە ID (خاوەن لە Secrets دایە و ناسڕدرێتەوە)
- **⚙️ ڕێکخستنەکان** — ژمارەی پرسیارەکان (نموونە: ١٠ یان «♾ هەمووی»)
  > 💡 ناوی مامۆستا لە پرسیاری دووەمی تۆمارکردندا بەکاردێت — ئەگەر ویستت بیگۆڕیت، بەستی `teacher_name` لە `data/db.json` بگۆڕە
- **📊 ئامار** — کۆی بەش، پرسیار، پەڕە، بەکارهێنەران، پرسیارە کراوەکان و تاقیکردنەوەی چالاک

## 🎨 فۆرماتکردنی دەق

لە دەقی پرسیار، هەڵبژاردە، تێبینی و وەڵامەکاندا دەتوانیت ئەم مارکەرانە بەکاربهێنیت:

| بنووسە | ئەنجام |
|--------|--------|
| `**وشە**` | قەڵەو (Bold) |
| `__وشە__` | لادان (Italic) |
| `~~وشە~~` | سڕینەوە (Strikethrough) |
| `\|\|وشە\|\|` | شاراوە (Spoiler — بە کلیک دەکرێتەوە) |
| `` `وشە` `` | کۆد (Monospace) |
| `{{وشە}}` | 🔴وشە🔴 — وشە بە سوور دیار دەکرێت (لە ویزاردی پرسیارشدا هەیە) |

هەروەها تێگی HTML ی ڕاستەوخۆ کاردەکات: `<b>` `<i>` `<u>` `<s>` `<code>` `<tg-spoiler>` `<a href="https://…">لینک</a>` `<blockquote>`

> ⚠️ تێلێگرام ڕێگە نادات ڕەنگی فۆنت بگۆڕدرێت — نزیکترین شت بە «سوور» بەکارهێنانی `{{وشە}}` یان ئیمۆجی 🔴ـە. ئەگەر HTML ـەکە هەڵە بێت، پەیامەکە بەبێ فۆرمات دەنێردرێت و چیتر نشکێت.

## 📥 هێنانی پرسیار بە JSON

لە پانێڵی ئادمین دوگمەی «📥 هێنانی پرسیار بە JSON» بکە و فایلەکە بنێرە (یان دەقەکە ڕاستەوخۆ بنێرە):

```json
[
  {
    "بەش": "بەندی یەکەم",
    "کەرت": "کەرتی یەکەم",
    "پرسیارەکان": [
      {
        "پرسیار": "کوردستان دەوڵەتێکە؟",
        "وێنە": "https://example.com/pic.jpg",
        "هەڵبژاردە": ["بەڵێ", "نەخێر"],
        "وەڵام": 1,
        "ڕوونکردنەوە": "💡 کوردستان وڵاتێکە"
      }
    ]
  }
]
```

**تێبینیەکان:**
- `وێنە` ئارەزوومەندانەیە — لینکی وێنە (http…) یان file_id ی تێلێگرام
- `وەڵام` دەتوانێت ژمارە بێت (١ = یەکەم هەڵبژاردە)، پیت (`A`)، یان هەمان دەقی هەڵبژاردەی ڕاست
- `ڕوونکردنەوە` ئارەزوومەندانەیە — تەنها لە وەڵامی هەڵەدا پیشان دەدرێت
- بۆ کەرتی ناوخۆیی قووڵتر: لەناو بەشەکەدا `"کەرتەکان": [ {"ناو": "کەرتی الف", "پرسیارەکان": […]} ]` بەکاربهێنە — بێ سنوور قووڵ دەبێتەوە
- ئەگەر بەشەکە پێشتر هەبێت، پرسیارەکان بۆ هەمان بەش زیاد دەکرێن (دووبارە بەش دروست نابێتەوە)
- دوای هێنان، لیستی هەڵەکان (ئەگەر هەبن) بە ژمارەی پرسیار پیشان دەدرێن

## ⏱ کارکردنی ٢٤ کاتژمێر / ٧ ڕۆژ

بۆت لەسەر GitHub Actions بەم شێوەیە بەردەوام دەمێنێتەوە:

1. هەر دانیشتێک **٥ کاتژمێر و ٥٠ خولەک** بەبێ پشوو کار دەکات (`POLL_SECONDS: "21000"` لە workflow ـەکە)
2. کاتێک دانیشتەکە تەواو دەبێت، GitHub دانیشتێکی چاوەڕوان (کە هەر ٥ خولەک جارێک ئامادە دەکرێت) **بە چەند چرکەیەک** دەست پێدەکاتەوە
3. ئەنجام: بۆت ~٩٩.٩٪ ی ڕۆژەکە ئۆنلاینە — پشووەکە تەنها چەند چرکەیەکە و ڕۆژانە نزیکەی ٤ جار ڕوودەدات
4. پەیامەکانی نێوان گۆڕینەکە بە تێلێگرام خەزن دەکرێن و بە خۆکاری دەگەن — **هیچ پەیام و وەڵامێک لەدەست ناچێت**

> ⚠️ سنووری GitHub: هەر دانیشتێک زۆرترین ٦ کاتژمێرە — بۆیە ٥ کاتژمێر و ٥٠ خولەک دانراوە بە پاشەکەوتی سەلامەت.
>
> ⚠️ لە ڕیپۆی **Public** دا ئەمە بەخۆڕایی و بێ سنوورە. لە ڕیپۆی **Private** دا مانگانە تەنها ٢٠٠٠ خولەکی خۆڕایی هەیە کە بەس نایەت (بۆت ڕۆژانە ~١٤٤٠ خولەک بەکاردەهێنێت) — بۆیە ڕیپۆکە **Public** بکە!
>
> ⚠️ GitHub هەر schedule ێک دوای ٦٠ ڕۆژ بێ چالاکی ناچالاک دەکات — تەنها یەک commit ی نوێ بکە (یان لە بۆتەکە پرسیار زیاد بکە — بۆت خۆی commit دەکات!) و دووبارە چالاک دەبێتەوە.

لەسەر کۆمپیوتەر داتا تەنها لە فایل هەڵدەگیرێت (بێ پوش بۆ GitHub — ئەگەر ڕیپۆی git هەبێت، خۆکارانە پوش دەکات).

## ❓ پرسیارە باوەکان

**داتاکان لە کوێن؟** لە `data/db.json` — هەموو گۆڕانکارییەک بە خۆکاری commit دەکرێت، بۆیە مێژووی git وەک باکئەپێک کاردەکات.

**چۆن شتێک بسڕمەوە؟** لە پانێڵی ئادمین، بەش/پرسیار/پەڕە بکەرەوە و دوگمەی 🗑 بکە (دوو هەنگاوی دڵنیابوون هەیە).

**وێنەی پرسیار چۆن هەڵدەگیرێت؟** تەنها `file_id` ی تێلێگرام — بۆیە هیچ فایلێک لە ڕیپۆدا نییە و ڕیپۆکە قورس نابێت.

**پرسیارەکان دەتوانن لە چەند بەشێک بن؟** هەر پرسیارێک لە یەک شوێندایە، بەڵام بەشەکان بێ سنوور قووڵ دەبنەوە — تاقیکردنەوەی هەر بەشی باوک هەموو پرسیارەکانی کەرتەکانی لەخۆ دەگرێت.

**وەڵام ناداتەوە؟** تابی Actions لە ڕیپۆکە ببینە — ئەگەر هەڵەیەک هەبێت لە لۆگەکەدا دەردەکەوێت. زۆربەی کاتان ئەوەیە کە Secretsـەکان سن نەنراون.
